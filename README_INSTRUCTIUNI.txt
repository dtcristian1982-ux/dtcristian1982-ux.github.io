PUBLICARE GITHUB PAGES
1. Creeaza repository PUBLIC numit dtcristian1982-ux.github.io
2. In repository alege Add file > Upload files; incarca cele 8 fisiere HTML/CSS/XML/TXT din arhiva (nu arhiva ZIP).
3. Commit changes. In Settings > Pages, selecteaza Deploy from a branch, main, /(root), Save.
4. Verifica https://dtcristian1982-ux.github.io/ si https://dtcristian1982-ux.github.io/sitemap.xml
5. Dupa ce site-ul functioneaza, adauga proprietatea URL prefix https://dtcristian1982-ux.github.io/ in Google Search Console si trimite sitemap.xml o singura data.
Site demonstrativ: preturile sunt scenarii ipotetice, nu tarife comerciale.
